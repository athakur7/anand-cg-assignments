🎨 Bootstrap Grid System

Learn to create responsive layouts with the 12-Column Grid System

📚 What is Bootstrap Grid System?

Think of the Bootstrap Grid System like a ruler divided into 12 equal parts. Each row on your website has exactly 12 columns, and you can divide them however you want to arrange your content (images, text, buttons, etc.).

💡 Simple Analogy: Imagine a newspaper layout with 12 vertical lines. You can use 1 line for a narrow sidebar, 5 lines for main content, and 6 lines for advertisement. That's how Bootstrap Grid works!

🔑 Key Concepts

🏗️ Container

The wrapper that holds everything. Options:

.container (fixed width)
.container-fluid (full width)

📏 Row

Horizontal line that holds columns.

<div class="row">...</div>

📊 Column

Individual units (1-12) for content.

.col-1 to .col-12

📱 Responsive

Changes based on screen size.

col-sm-, col-md-, col-lg-

✅ Example 1: Basic HTML Structure

Here's the minimum code you need to get started:

<!-- Container: Wrapper for everything --> <div class="container"> <!-- Row: Horizontal container --> <div class="row"> <!-- Column 1: Takes 6 out of 12 units (50% width) --> <div class="col-6"> Content goes here </div> <!-- Column 2: Takes 6 out of 12 units (50% width) --> <div class="col-6"> More content here </div> </div> </div>

⭐ Best Practices & Tips

✓ Always sum to 12: Make sure columns in a row add up to 12. Example: 4+4+4=12, 6+6=12, 3+3+3+3=12
✓ Use containers: Always wrap rows in .container or .container-fluid
✓ Responsive classes: Use col-sm-, col-md-, col-lg- for different devices
✓ Add gutters: Bootstrap adds automatic spacing between columns (gutters)
✓ Mobile first: Start with mobile layout, then add larger screen classes
✓ No limit on rows: You can have as many rows as you want - Bootstrap doesn't restrict this

Bootstrap 12-Column Grid Information:

  • Total Columns: 12 (Fixed in Bootstrap grid)
  • Number of Rows: Unlimited/Unlimited as per feasibility
    • No hard limit on rows - depends on content and performance
    • Each row can have multiple responsive columns
    • Typically 3-5 rows per section is recommended for UX
  • Column Options: col-1, col-2, col-3, col-4, col-5, col-6, col-7, col-8, col-9, col-10, col-11, col-12
  • Responsive Prefixes: col-sm-, col-md-, col-lg-, col-xl-, col-xxl-
  • Equal Width: Use .col without number for equal-width columns
