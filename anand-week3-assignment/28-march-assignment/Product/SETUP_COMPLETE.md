## 🧪 Testing Examples

### Using Swagger (Easiest)
1. Run: `dotnet run`
2. Open: https://localhost:7091/swagger
3. Click endpoint → "Try it out" → "Execute"

### Using PowerShell
```powershell
# Get all products
Invoke-RestMethod -Uri "https://localhost:7091/api/product" -Method Get

# Create product
$body = @{
    name = "USB Cable"
    price = 15.99
    category = "Accessories"
} | ConvertTo-Json

Invoke-RestMethod -Uri "https://localhost:7091/api/product" `
    -Method Post -ContentType "application/json" -Body $body
```

### Using cURL
```bash
# Get all products
curl -X GET "https://localhost:7091/api/product" -H "accept: application/json"

# Create product
curl -X POST "https://localhost:7091/api/product" ^
  -H "Content-Type: application/json" ^
  -d "{\"name\":\"USB Cable\",\"price\":15.99,\"category\":\"Accessories\"}"
```

## ❓ Troubleshooting

### Port Already in Use
- The app will automatically use a different port
- Check console output for the actual URL

### Database Connection Error
- Verify SQL Server is running on localhost:1433
- Check connection string in appsettings.json
- Verify username/password

### Swagger Not Loading
- Ensure app is running in Development mode
- Check Swashbuckle.AspNetCore is installed
- Verify Swagger middleware in Program.cs

### Migration Issues
- Delete Migrations folder (not recommended)
- Run: `dotnet ef database drop`
- Run: `dotnet ef migrations add InitialCreate`
- Run: `dotnet ef database update`
