# TechVision - Modern Interactive Website

A professional, fully interactive digital agency website with modern design and smooth animations.

## 🎨 Features

### Main Website (template.html)
- **Responsive Design**: Mobile-friendly layout that adapts to all screen sizes
- **Modern UI/UX**: Clean, professional design with gradient effects
- **Interactive Navigation**: Sticky navigation with active state highlighting
- **Hero Section**: Eye-catching headline with call-to-action buttons
- **Services Grid**: Animated service cards with hover effects
- **Portfolio Showcase**: Featured projects with overlay descriptions
- **Animated Statistics**: Counter animation that triggers on scroll
- **Mobile Menu**: Hamburger menu for mobile devices
- **Smooth Scrolling**: Seamless navigation between sections
- **Scroll Animations**: Elements fade in as you scroll down
- **Scroll to Top Button**: Floating button appears after scrolling
- **Footer**: Multi-column footer with links and social media

### Contact Page (form1.html)
- **Professional Contact Form**: Beautiful split layout design
- **Real-time Validation**: Input validation with helpful error messages
- **Contact Information**: Company details with icons
- **Interactive Elements**: 
  - Loading state while submitting
  - Success message after submission
  - Auto phone number formatting
  - Focus states with smooth transitions
- **Responsive Grid**: Two-column layout on desktop, single column on mobile

## 🚀 Interactive Features

1. **Mobile Menu Toggle**: Click the hamburger menu on mobile to open/close navigation
2. **Smooth Scroll**: Click any navigation link for smooth scrolling to sections
3. **Stats Counter**: Watch numbers count up when you scroll to the stats section
4. **Service Cards**: Hover over service cards for animated effects
5. **Portfolio Items**: Click portfolio items for pulse effects
6. **Form Validation**: Try submitting the form without filling required fields
7. **Ripple Effect**: Click buttons to see a ripple animation
8. **Parallax Hero**: Hero section moves at different speed when scrolling
9. **Active Nav Links**: Navigation automatically highlights based on scroll position
10. **Scroll to Top**: Button appears after scrolling down the page

## 📁 Files

- `template.html` - Main landing page
- `form1.html` - Contact form page
- `style.css` - Comprehensive styling with modern CSS features
- `script.js` - JavaScript functionality for interactivity

## 🎯 How to Use

1. Open `template.html` in your web browser to view the main website
2. Navigate through sections using the navigation menu
3. Click "Contact Us" or the contact button to go to the form page
4. Test the interactive features by:
   - Hovering over service cards and portfolio items
   - Scrolling to see animations and stats counter
   - Testing the mobile menu (resize browser window)
   - Filling out the contact form
   - Using the scroll-to-top button

## ✨ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern features including:
  - CSS Grid & Flexbox
  - CSS Variables (Custom Properties)
  - Gradients & Animations
  - Transitions & Transforms
- **JavaScript (Vanilla)**: No frameworks, pure JS for:
  - DOM Manipulation
  - Event Handling
  - Intersection Observer API
  - RequestAnimationFrame for smooth animations

## 🔥 Performance Features

- Smooth 60fps animations using requestAnimationFrame
- Lazy loading animations with Intersection Observer
- Optimized CSS with hardware-accelerated transforms
- Minimal JavaScript for fast load times
- No external dependencies or libraries
