FURTHER HTML EXTRA NOTES
========================

Advantages of form:
-------------------
1) Collecting names, addresses, telephone numbers, e-mail address and other information to register users for a service or an event.
2) Gathering information for the purchase of an item. For example, if we want to purchase a book on the internet, we have to fill all relevant information.
3) Collecting feedback from the website.
4) Providing a search tool for the website, so users can locate information faster.

To write a form we first use <form> tags.

Important form attributes:
--------------------------
1) Accept:
   Defines the list of MIME types recognized by the server that processes the form.
   Syntax:
   ACCEPT="internet media type"
   This attribute is used rarely.

2) Action:
   Tells where the form should go when the user clicks the submit button.
   Syntax:
   ACTION="URL"

3) Method:
   Specifies the method by which data is sent to the server.
   If value is GET, browser appends query values in URL.

   Syntax:
   <form action="url" method="get">
     contents of the form
   </form>

Example on GET method:
----------------------
Use GET when sending less, non-sensitive data.

<html>
<head>
<title>form demo</title>
</head>
<body>
<h2>Join the Mailing List:</h2>
<form action="doc1.html" method="get">
<pre>
First Name: <input type="text" name="first">
Last Name:  <input type="text" name="last">
<input type="submit">  <input type="reset">
</pre>
</form>
</body>
</html>

HTML INPUT ELEMENTS:
--------------------
The <input> element defines the type and appearance of controls to be displayed on the form.

Common attributes:
1) type: text, password, checkbox, etc.
2) name: name of the control.
3) value: optional value (often used with radio).
4) size: width of control (example: size=30).
5) maxlength: maximum number of characters in text/password.
6) checked: boolean attribute for checkbox/radio default selection.
7) src: used when input type is image.

Button:
-------
<input type="button" value="click" name="b1">

Text:
-----
<input type="text" value="" name="username" size="20">

Checkbox:
---------
Use checkboxes when multiple options can be selected.

<input type="checkbox" name="courses" value="check-box1"> C language <br>
<input type="checkbox" name="courses" value="check-box2" checked> Java

Submit:
-------
<input type="submit" value="click" name="b1">

Image:
------
This creates a graphical submit button.
<input type="image" src="url" name="blue_bulb">

Reset:
------
Clears form values.
<input type="reset" value="reset" name="b2">

TextArea Element:
-----------------
Creates multiline text input control.
Specify rows and columns.

<textarea name="text1" cols="20" rows="5"></textarea>

Select Element:
---------------
Used to display a list of choices for user.
Each choice is represented by an <option> element.
A select must contain at least one option.

Optgroup Element:
-----------------
Used to group related options in hierarchy.
