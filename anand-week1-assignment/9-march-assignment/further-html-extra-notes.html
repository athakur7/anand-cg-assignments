Further HTML Extra Notes

Advantages of Form

  • Collecting names, addresses, telephone numbers, e-mail address and other information to register users for a service or an event.
  • Gathering information for purchase of an item, for example when buying a book online we fill all relevant information.
  • Collecting feedback from website users.
  • Providing a search tool for the website, so users can locate information faster.

Form Tag and Attributes

To write a form, we first use the <form> tag.

1) Accept

Defines the list of MIME types recognized by server scripts.

ACCEPT="internet media type"

This attribute is used rarely.

2) Action

Tells where the form data should be sent when submit is clicked.

ACTION="URL"

3) Method

Specifies how form data is sent to server. Common values are GET and POST.

<form action="url" method="get">
  contents of the form
</form>

Example on GET Method

When we send very little non-sensitive data, we can use GET method.

<html>
<head>
<title>form demo</title>
</head>
<body>
  <h2>Join the Mailing List:</h2>
  <form action="doc1.html" method="get">
    <pre>
First Name: <input type="text" name="first">
Last Name:  <input type="text" name="last">
<input type="submit">  <input type="reset">
    </pre>
  </form>
</body>
</html>

HTML Input Elements

The <input> element defines the type and appearance of controls in a form.

  • type: text, password, checkbox, radio, etc.
  • name: control name.
  • value: optional control value.
  • size: width of text/password controls.
  • maxlength: max number of characters allowed.
  • checked: boolean attribute for checkbox/radio default selection.
  • src: image source when type="image" is used.

Button

<input type="button" value="click" name="b1">

Text

<input type="text" value="" name="username" size="20">

Checkbox

<input type="checkbox" name="courses" value="check-box1"> C language <br>
<input type="checkbox" name="courses" value="check-box2" checked> Java

Submit

<input type="submit" value="click" name="b1">

Image Submit

<input type="image" src="url" name="blue_bulb">

Reset

<input type="reset" value="reset" name="b2">

TextArea Element

Creates multiline text input. We specify rows and columns.

<textarea name="text1" cols="20" rows="5"></textarea>
