🔄 Example 7: The Original Code Explained
What does it demonstrate?
Row 1: Simple 2-column layout
col-lg-6 + col-lg-6 = 12 cols
Row 2: Responsive change - columns behave differently on different screen sizes
Large: 2+8+2 = 12 Medium: 8+3+1 = 12 Small: 6+1+5 = 12
Row 3: Contains 2 columns
col-lg-6 + col-lg-6 = 12
Row 4 (NESTED): A row INSIDE Row 3's second column!
Nested Row 4: col-lg-8 + col-lg-4 = 12 (But only takes up 6 cols parent width)
✅ Key Takeaways - When to Use Nested Rows
✓ Use Nested Rows For:
  • Product cards with image + price + buttons
  • Comments with nested replies
  • Dashboard sections with sub-stats
  • Team cards with avatar + info + links
  • Reviews with user + rating + text
  • Complex form sections
  • Blog posts with comments section
💡 Remember:
  • Nested rows are relative to their parent column width
  • Always add a new .row class inside a .col-* div
  • Columns in nested row still add up to 12
  • Mobile-first approach: Add col-12 first, then responsive classes
  • Use for organizing complex, hierarchical content
  • Makes code cleaner and more maintainable
  • Perfect for real-world websites and apps
